# Staycation Platform  

Staycation is a web-based platform that allows users to explore and book accommodations with ease. This project includes both a frontend and backend implementation, featuring modern web development technologies.  

---

## **Frontend**  
**URL**: [Staycation Frontend](https://staycation-phi.vercel.app)  

### **Tech Stack**  
- **React** (with Vite)  
- **Zustand** (state management)  
- **Midtrans Snap Sandbox** (payment gateway integration)  
- **Axios** (HTTP requests)  
- **Ant Design (Antd)** (UI components)  
- **React Hook Form** & **Yup** (form validation)  

---

## **Backend**  
**Local Server (Ngrok)**: [Staycation Backend](https://089d-111-95-40-2.ngrok-free.app)  

### **Tech Stack**  
- **Node.js** (runtime environment)  
- **Express.js** (backend framework)  
- **Sequelize** (ORM for database management)  
- **JWT** (authentication)  
- **Midtrans** (payment gateway integration)

## **Features**  
### **Frontend**:  
- User-friendly UI for browsing and booking accommodations.  
- Integrated payment gateway using **Midtrans Snap Sandbox**.  
- State management with **Zustand** for optimal performance.  
- Form handling and validation using **React Hook Form** and **Yup**.  

### **Backend**:  
- Secure authentication using **JWT**.  
- Efficient database management with **Sequelize**.  
- Payment processing via **Midtrans API**.  
- Scalable and modular structure with **Express.js**.

## **Setup Instructions**  
### **Frontend**  
1. Clone the frontend repository.  
2. Navigate to the project directory.  
3. Install dependencies:  
   ```bash  
   npm install  
   ```  
4. Run the development server:  
   ```bash  
   npm run dev  
   ```  

### **Backend**  
1. Clone the backend repository.  
2. Navigate to the project directory.  
3. Install dependencies:  
   ```bash  
   npm install  
   ```  
4. Set up environment variables (e.g., database credentials, JWT secret, Midtrans API keys).  
5. Start the server:  
   ```bash  
   npm run dev  
   ```
